# Contributing to the Australian Accounting Technology Index

Guidelines for contributing open-source libraries, statutory datasets, and technical resources for Australian accounting technology.

### Guidelines for Submissions
1. **Australian Scope**: Entries must be directly applicable to Australian accounting, tax, superannuation, payroll, or financial reporting.
2. **Quality & Maintenance**: Projects should have clear documentation, tests where applicable, and active maintenance.
3. **No Commercial Promotion**: Submissions must consist exclusively of open-source software, official public sector resources, or free developer interfaces.
4. **Formatting**: Ensure your entry follows the existing format:
   - `- **[Project Name](link)** - Brief description highlighting key features and relevance.`

### Pull Request Process
1. Fork the repository.
2. Add your suggestion to the relevant section alphabetically or logically.
3. Submit a pull request with a brief explanation of why the resource is valuable.
